<objective>
Fechar REQ-03 (D-03/CONTEXT.md — alongamento com condução: exercícios nomeados + tempo, e
pedido de foco no chat de onboarding refletido na condução): expandir o catálogo de
`Mobilidade` com entradas nomeadas por grupo muscular (hoje só 4 genéricas) e reforçar o
prompt do molde para efetivamente usar `diretrizes.preferencias` — que já chega ao prompt sem
mudança de schema — na escolha desses exercícios.

Purpose: a pesquisa confirmou que o encanamento "foco no chat → prompt" já existe
(`PostQuestionnaireChat` → `/api/consolidate-chat` → `diretrizes.preferencias` → prompt do
molde); o que falta é (a) o catálogo ter nomes específicos o bastante para a IA escolher, e
(b) uma instrução explícita para ela de fato usar `preferencias` nessa escolha — texto solto no
prompt sem instrução dedicada não muda comportamento (RESEARCH.md, Pitfall 3). NENHUM campo
novo entra no schema do molde (`molde_schema.py`) — decisão deliberada desta fase, per
CONTEXT.md: representação por duração (`duracao_minutos`, já suportado e já renderizado pelo
SessionPlayer) evita a porta de mão única de mexer no schema estruturado.
Output: catálogo expandido (aditivo, sem migration), instrução nova em `_INSTRUCOES_MOLDE`,
testes cobrindo ambos, e confirmação humana de que uma geração REAL respeita o pedido de foco
(não automatizável sem custo/latência de chamada real à API de IA).
</objective>
