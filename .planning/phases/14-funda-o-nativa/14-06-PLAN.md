  <how-to-verify>
    Roteiro auto-contido (D-10) — rode na ordem, com o iPhone conectado ao Mac
    por cabo (D-02):

    1. Se ainda não pareado: Xcode → Window → Devices and Simulators →
       aguardar o Mac reconhecer o iPhone.
    2. No iPhone: Settings → Privacy &amp; Security → Developer Mode → ativar
       (o aparelho reinicia) — só necessário na primeira vez.
    3. Descobrir o UDID: `xcrun devicectl list devices`.
    4. Instalar: `xcrun devicectl device install app --device &lt;UDID&gt;
       &lt;caminho-do-.app-de-14-05-SUMMARY.md&gt;`.
    5. Abrir o app pela primeira vez no iPhone. Se aparecer "Untrusted
       Developer": Settings → General → VPN &amp; Device Management → confiar
       no perfil do Apple ID pessoal, depois reabrir o app.
    6. Confirmar que o app abre normalmente (fora do Expo Go), mostrando a
       tela de login/home — item (a).
    7. Round-trip do spike: adicionar temporariamente o widget
       "session-widget" à Home Screen ou Lock Screen (aciona o processo da
       extensão, que escreve o valor de teste no App Group), depois abrir o
       app principal e observar se ele consegue ler de volta o valor gravado
       pelo widget (via `readAppGroupSpikeValue()` — visível no Console.app do
       Mac filtrando pelo processo do app, ou em qualquer saída de debug que o
       build Debug já exponha) — item (b).
    8. Reportar EXATAMENTE neste formato: `app=PASS|FAIL`,
       `round-trip=PASS|FAIL|AMBIGUO`, com o erro exato do Xcode/Console se
       houver falha. "AMBIGUO" é a resposta certa se o round-trip funcionar só
       em um sentido, ou de forma inconsistente entre tentativas — não
       adivinhar.
  </how-to-verify>
