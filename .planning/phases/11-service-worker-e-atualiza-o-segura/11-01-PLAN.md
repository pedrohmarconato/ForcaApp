<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser (Service Worker) ↔ Vercel edge/CDN | `sw.js` controla todas as respostas de navegação do domínio depois de instalado; a Vercel só precisa servir os arquivos certos com os headers certos. |
| Build pipeline (buildCommand da Vercel) ↔ artefato gerado (dist/sw.js) | `workbox generateSW` roda no build e produz o único arquivo que vira autoridade de cache no navegador do usuário. |
| Página (register-sw.js) ↔ Service Worker (postMessage/eventos) | Só código do mesmo domínio, no mesmo escopo de registro, pode mandar mensagem para o SW — garantia da própria plataforma. |
| npm registry ↔ devDependency (workbox-cli) | Cadeia de suprimento do pacote que gera o artefato de produção. |
